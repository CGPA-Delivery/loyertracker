# Guide de migration CGPA v5.6 vers v6.0

1. Lire Project State et conserver phase, Gates, decisions et risques.
2. Corriger toute incoherence de version v5.6.
3. Evaluer l'applicabilite UI, Frontend et Angular.
4. Conserver Gate 02A et Gate 04A comme UX Gate et Design Gate.
5. Adopter UXR-001, DesignOps et Frontend Architecture au prochain changement significatif.
6. Enrichir DDS, DSG, backlog et preuves qualite.
7. Activer les agents selon le routage v6.0.
8. Executer la checklist de migration et mettre a jour Project State.

Aucun Gate historique n'est rejoue. Les exemptions sont explicites et datees.
