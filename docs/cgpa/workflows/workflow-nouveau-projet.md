# Workflow — Workflow Nouveau Projet

1. Créer la fiche idée.
2. Passer Gate 00.
3. Produire expression de besoin et faisabilité.
4. Identifier si le projet comporte une interface utilisateur.
5. Si interface utilisateur, produire les livrables UX-01 a UX-04 et tenir Gate 02A.
6. Si backend/API-only, tracer l'exemption Gate 02A.
7. Produire CDC, architecture, backlog et DevSecOps.
8. Valider Gates 01 à 06.
9. Autoriser le développement uniquement après validation suffisante.

## Livrable final

Décision documentée, score mis à jour et actions suivies.
