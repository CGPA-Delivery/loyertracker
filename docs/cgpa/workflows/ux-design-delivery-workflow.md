# Workflow - UX & Design Delivery

## Flux

Expression du besoin -> UX Research -> UX Gate -> Cahier des charges -> Architecture -> Wireframes -> DDS -> Prototype -> Design Review -> DSG -> Design Gate -> Backlog -> Developpement -> Visual Review -> Recette -> Production.

## Regles

1. Gate 02A valide le cadrage UX precoce.
2. Phase 04 stabilise les contraintes d'architecture.
3. Phase 04A produit les artefacts implementables.
4. Gate 04A autorise ou refuse le Frontend.
5. Chaque User Story Frontend reference ecran, composant, DDS et criteres accessibles applicables.
6. La Revue Design compare l'implementation aux UI Specifications et DSG-001.
7. Les ecarts creent une correction, une dette acceptee ou une nouvelle DDS.
8. La recette et la Production conservent leurs Gates existants.
9. UXR-001 trace les revues UX et le Visual Review Report trace la conformite implementee.
