## Applicabilite

* [ ] Projet avec interface utilisateur.
* [ ] Exemption backend/API-only documentee si non applicable.

## UX-01 - User Journey Governance

* [ ] Personas documentes.
* [ ] User journeys documentes.
* [ ] Parcours critiques identifies.
* [ ] Cas nominaux documentes.
* [ ] Cas d'erreur documentes.

## UX-02 - Information Architecture

* [ ] Navigation globale definie.
* [ ] Menus documentes.
* [ ] Structure des ecrans documentee.
* [ ] Relations entre modules documentees.

## UX-03 - Design System

* [ ] Couleurs definies.
* [ ] Typographie definie.
* [ ] Espacements definis.
* [ ] Icones definies.
* [ ] Responsive strategy definie.
* [ ] Accessibilite minimale definie.

* [ ] Dashboard principal maquetté.
* [ ] Navigation maquettée.
* [ ] Ecrans metier principaux maquettés.
* [ ] Formulaires critiques maquettés.
* [ ] Validation Product Owner obtenue.
