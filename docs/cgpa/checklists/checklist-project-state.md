# Checklist — Project State File

- [ ] Le fichier `/docs/project-state.md` existe.
- [ ] Le fichier est à jour par rapport au dernier changement significatif.
- [ ] La phase CGPA actuelle est renseignée.
- [ ] Le gate actuel est renseigné.
- [ ] Le statut du gate est renseigné.
- [ ] La décision actuelle Go / Go sous réserve / No Go est renseignée.
- [ ] La prochaine action claire est explicitement indiquée.
- [ ] Les décisions structurantes sont historisées.
- [ ] Les étapes réalisées sont historisées.
- [ ] Les risques ouverts sont listés avec niveau, impact, mitigation et statut.
- [ ] Le score de maturité CGPA est actualisé.
- [ ] Les informations obsolètes sont signalées ou corrigées.
- [ ] Aucun historique important n'a été supprimé sans demande explicite.
- [ ] Les écarts entre le dépôt et le Project State sont signalés.
- [ ] Le Project State complète le Plan d'Exécution sans le remplacer.
