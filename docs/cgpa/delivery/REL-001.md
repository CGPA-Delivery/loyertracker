# REL-001 - Release Governance Standard

## Objectif

Definir la gouvernance des releases CGPA v6.1.

## Types de release

* Release Candidate : artefact candidat a la Production.
* Scheduled Release : release planifiee.
* Hotfix : correction urgente et limitee.
* Patch Release : correction non urgente.
* Minor Release : ajout fonctionnel compatible.
* Major Release : changement structurant ou potentiellement incompatible.
* Rollback Release : retour controle vers un etat stable.

## Regles

* Toute Release Candidate doit etre identifiable, versionnee et immutable.
* La Production est pilotee par Release, Epic ou Hotfix valide.
* Les release notes sont obligatoires avant Production.
* Le rollback est obligatoire avant Production.
* CHECK-REL-01 est obligatoire avant Gate Production.

## Preuves attendues

* tag ou version ;
* changelog ;
* release notes ;
* artefact candidat ;
* validation metier ;
* validation technique ;
* rollback ;
* decision Release Manager.
