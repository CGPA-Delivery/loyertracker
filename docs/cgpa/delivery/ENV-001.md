# ENV-001 - Environment Governance Standard

## Objectif

Gouverner les environnements Local, Dev, Integration, QA, Staging, Pilot et Production.

## Environnements

| Environnement | Objectif | Promotion |
| --- | --- | --- |
| Local | Developpement individuel | aucune |
| Dev | Integration technique | CI conforme |
| Integration | Tests inter-composants | validation technique |
| QA | Validation qualite | campagne QA |
| Staging | Pre-production | Gate Staging |
| Pilot | Exposition limitee | decision release |
| Production | Service reel | Gate Production |

## Regles

* Production et Staging doivent etre separes.
* Les donnees sensibles hors Production doivent etre protegees, anonymisees ou justifiees.
* Les secrets sont propres a chaque environnement.
* Les URLs, ports, volumes, reseaux et variables doivent etre documentes.
* Les proprietaires d'environnement doivent etre identifies.

## Preuves attendues

* inventaire des environnements ;
* criteres d'entree et de sortie ;
* strategie secrets ;
* strategie donnees ;
* strategie rollback ;
* statut dans `/docs/project-state.md`.
