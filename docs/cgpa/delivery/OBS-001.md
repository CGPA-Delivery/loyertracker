# OBS-001 - Observability Readiness Standard

## Objectif

Garantir qu'une application promue en Production est observable, supervisable et exploitable.

## Controles minimaux

* logs applicatifs disponibles ;
* logs techniques disponibles ;
* metriques systeme suivies ;
* metriques applicatives critiques suivies ;
* traces ou correlation d'erreurs si applicable ;
* dashboards disponibles selon le risque ;
* alertes critiques definies ;
* smoke tests Production definis ;
* procedure d'escalade identifiee.

## Avant Production

CHECK-OPS-01 doit confirmer que l'equipe peut detecter rapidement une regression, une indisponibilite, une erreur critique ou une degradation de performance.

## Apres Production

Le monitoring post-release doit etre execute et le rapport de release mis a jour.

## Decision

PASS, PASS sous reserve ou FAIL.
